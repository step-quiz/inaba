# CLAUDE.md

Before doing anything in this repository, read [`HANDOUT.md`](HANDOUT.md): it is the full handover (user
rules, the **two kinds of task** — A: implement a pending web puzzle, B: make the printable PDF of a finished
one —, architecture, data pipeline, testing). Talk to the user in Catalan; never use `[skip ci]` in commits;
open the PR yourself when the work is done (for task B, only after the user has said OK to pages 1 and 3).
Naoki Inaba is the author of every puzzle: keep his credit in the header and footer of every page, never put a
licence (CC, MIT…) over the puzzles, and do not publish `src/` (see the top of `HANDOUT.md`).
